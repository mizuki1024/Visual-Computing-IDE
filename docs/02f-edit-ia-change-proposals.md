### CP-16. 確認ダイアログの規則の拡張（`03` 原則9・UXR-23〜25）

| 項目 | 内容 |
| --- | --- |
| 現状 | UXR-23「A群でモーダルの確認ダイアログを 0」、UXR-25「取り消せる操作には確認を付けない。取り消せない操作は A群に存在しない」 |
| 変更案 | 編集トラックの**通常の編集フロー**（値の編集・下書き・破棄・適用・適用の取り消し・アートボードの開閉）では確認ダイアログを置かない（0.3 で範囲を明記）。**既存の危険操作の規則 — NFR-23（二段階の確認）、UXR-25 の C群の削除・デプロイ、FR-74、FR-54 — は撤廃しない。** 通常の編集フローでは代わりに: ①**適用は差分確認の画面（S-14）の中でだけ押せる**（差分を見ること自体が確認）②取り消しに条件が付く操作（外部変更の後の適用の取り消し）は、**押す前に条件と結果をインラインで示す** ③取り消せない書き込みは作らない（外部の変更の上書きを用意しない）④新規プロジェクトの作成は、空でない場所を選べない（確認ではなく拒否）（`03e` 6章） |
