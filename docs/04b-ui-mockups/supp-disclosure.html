説明をどの段階に置くか — 3案に共通の規則

A案の改善3案はキャンバス上の説明文を減らし、同じ説明をホバー・詳細パネルへ移した。 文章の総量は減らしていない。置き場所を変えただけである（03b 4.1節の5段階に対応）。

キャンバスに語を残すのは「観測できていないこと」だけ：推定の2ホップ（「推定」チップ・★）と、 切断1件の理由（UI-07 によりキャンバスのみ）。実測の5ホップには語を置かない。

段階1（ホバー）の1行カード静止画では未検証
キャンバスから外した「この通信を受けたサーバーの処理」は、ホバーで初めて出る。 観測性の語（実測／推定）を必ず同じカードに載せる。表示の遅延・消え方は静止画では検証できない（04 8章 未決定5）。
ノードの状態の記号正常は無表記
ノード上に置くのは種別アイコン・ステップバッジ・短いラベル・状態のみ。 正常には記号を置かない（経路に対する肯定記号を使わない・UXR-12）。色に頼らず形で区別する（NFR-30）。 本モックの7ノードはすべて正常のため、記号は出ていない。
