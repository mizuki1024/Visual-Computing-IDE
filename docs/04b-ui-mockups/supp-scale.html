ノード数が増えたときに、3案の骨格がどう変わるか

S-04 を開いた直後の既定スコープは T2（主トレース・選択前）であり、ページによっては数十ノードが並ぶ （02b 3.1節 / 03 P3-03）。本図は 3案の幾何がどう伸びるかだけを描いた骨格スケッチである。 集約の段は 03 5.3節（段0〜段3）に従い、削除・非描画は行わない。

これは検討用スケッチであり、描画性能・可読性を実測したものではない。 段の発動条件（B-03 / B-04）は 03 5.5節の UR-07 検証が済むまで確定しない。ノード数・件数は仮置きである。
A-1 の骨格縦帯 + 縦積み
帯の内側でノードが縦に積み上がる。1帯あたり約6ノードで縦が尽きるため、段1（同種連続の集約）が最も早く発動する。戻りレーンは下辺に1本のまま。
A-2 の骨格行 = 1経路
往路が水平1行のため、経路が増えても行が増えるだけで形は変わらない。戻りは共通レーンに束ねられる。横幅（3層ぶん）が先に制約になる。
A-3 の骨格面 + 大きいノード
ノードが大きく余白も広いため、1画面に置ける個数が3案で最も少ない。段1を飛ばして段2（境界グループ単位）へ移る想定になる。
