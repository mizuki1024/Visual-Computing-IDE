# 試用の手引き — 画面の値が「どこから来たか」をたどる

この手引きは、限定試用に参加する方のためのものです。プログラムや DB に詳しくなくても進められるように書いています。所要時間は約 20 分です。

> **題材は決まっています。** 練習用の小さなアプリ（`poc01-fixture-app`。架空の地名と連番だけのデータ）を使います。ご自身のプロジェクトでは使いません。
> 準備（DB・IDE の起動）は進行役が済ませています。困ったら、いつでも進行役に声をかけてください。

---

## 0. 画面の見方（最初に1分）

| 場所 | 何があるか |
| --- | --- |
| 左上「プレビュー」 | 題材のアプリの画面そのもの。ここで値を選びます |
| 中央（暗い点の背景） | **経路図**。選んだ値が、どのコードで描かれ、どこから来たかを図で描きます |
| 右端「詳細」 | 経路図の読み方を文章で出します。**迷ったら、まずここを読みます** |
| 右上「プロジェクトと実行」 | 題材のアプリを起動・停止する場所 |

画面の幅は **1600×1000 以上** をおすすめします（1440×900 でも使えますが、図の文字が小さくなります）。

---

## 1. 開く

1. 右上「プロジェクトと実行」のパス欄に、進行役から伝えられたパス（例: `/home/…/poc/fixture-app`）が入っているか確かめます。
2. ［検出］を押します。`対応` と `poc01-fixture-app` が出れば成功です。

このとき中央と右端には「**プロジェクトを開きました（まだ起動していません）**」と出ます。**まだ何も図が無いのが正しい状態です。**

> 「合成デモを見る」というボタンがあります。これは**別のアプリの見本**（架空の物件一覧）で、画面の見方を試すためのものです。押すと「合成デモを表示中 — あなたのプロジェクトのデータではありません」と出ます。［デモを閉じる］で戻ります。今回の試用では押さなくてかまいません。

## 2. 起動する

1. 「プロジェクトと実行」の［起動する］を押します。
2. 数秒〜十数秒で、左上のプレビューに題材のアプリのページが出ます。上の帯に「実行中」と緑の点が出ます。

起動中、中央には「**開発サーバーを起動しています**」、起動が終わると「**まだ経路がありません**」と出ます。これも正しい状態です（まだ値を選んでいないため）。

## 3. 値を選ぶ

1. プレビューの上のアドレス欄に `/lin-a` と入れて［移動］を押します。「ケースA 直接対応」のページが出ます。
2. プレビューの［選択］を押します（選択モードに入ります）。
3. ページの中の地名（例: 「アオバ台」）を1つクリックします。
4. もう一度［選択］を押して、選択モードを抜けます。すると中央の経路図が大きく広がります。

> ページに戻りたいときは、プレビューの［ページを表示］を押します。パネルは ✕ で閉じるより［畳む］のほうが、ページがそのまま残ります。
> ページの中のリンクで別のページに移ったときは、↻（再読み込み）を押してから選んでください（リンクで移った直後の選択は、まだうまく結べません）。

## 4. 値の由来を見る

右端「詳細」のいちばん上を読みます。

* **この値の出所**: `poc.listings . region` — この地名は、DB の `listings` という表の `region` という列から来た、という意味です。
* その横の **「推定」**: この結び付きの一部は、実際に値の受け渡しを見たのではなく、**コードの形から推測した**ものだ、という印です。
* **★ いちばん弱いところ**: 推測が入っている箇所です。［ここを見る］を押すと、図のその線が選ばれます。

経路図では、**実線＝実際に起きたことを観測した関係**、**破線＝推定した関係**です。左下「表示設定」に凡例があります。

数字キー（1〜9）で図の番号の箇所を選べます。Esc で1段ずつ戻ります。［全体表示］（または 0 キー）で図全体を収めます。

## 5. 「未確認」の意味を理解する

1. アドレス欄に `/lin-g` と入れて［移動］します。「ケースG 否定例」のページが出ます。
2. ［選択］を押し、いちばん下の「**表示用の固定ラベル**」をクリックし、もう一度［選択］を押します。

右端「詳細」は、今度は次のように出ます。

| 行 | 表示 | 意味 |
| --- | --- | --- |
| 描画位置 | **特定済み**　実測　`src/app/lin-g/page.tsx:28` | この文字を画面に描いた**コードの場所**は、実際に確かめられた |
| 値の由来 | **未確認** | この文字が DB の**どの列から来たかは分かっていない** |
| 切れた段階 | 静的解析 | どの段で調べがつかなくなったか（ここではコードの解析） |
| 理由 | 参照の連鎖を解けません… | なぜ結べなかったか |

ここが大切です。

* 「**実測**」は描画位置（コードの場所）までの話です。値が DB から来たことが実測で分かった、という意味ではありません。
* 「**未確認**」は「調べたが、根拠をもって結べなかった」という意味です。**推測で埋めることはしません。** このページの文字は、実際には DB の値ではなくコードに直接書かれた固定の文字です。だから結べないのが正しい答えです。

ほかに「描画位置: 特定できません」と出ることもあります。これは、選んだ要素を描いたコードの場所そのものが分からなかった、という意味です（例: 外部の部品の中の要素）。

## 6. 終わる

「プロジェクトと実行」の［停止する］を押します。中央と右端は「**開発サーバーは停止しています**」になり、それまでの図は消えます（停止した後の古い情報は出しません）。もう一度［起動する］を押すと、新しい観測から描き直します。

---

## 困ったとき

| こうなった | こうする |
| --- | --- |
| 中央に何も図が無い | 値をまだ選んでいません。3. の手順で値を選びます |
| 図がパネルに隠れて見にくい | ［全体表示］（0 キー）を押します |
| 選んでも何も起きない | ［選択］が押された状態か確かめます。ページを移った直後なら ↻ を押してから選びます |
| 見慣れない物件一覧や「千葉県」が出ている | 合成デモ（別のアプリの見本）です。［デモを閉じる］で戻ります |
| 「起動できていません」と出た | 進行役を呼んでください |
