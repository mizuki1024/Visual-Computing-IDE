# 試用の手引き — 画面の値が「どこから来たか」をたどる

この手引きは、限定試用に参加する方のためのものです。プログラムや DB に詳しくなくても進められるように書いています。所要時間は約 25 分です。

> **題材は決まっています。** 練習用の小さなアプリ（`poc01-fixture-app`。架空の地名と連番だけのデータ）を使います。ご自身のプロジェクトでは使いません。
> 準備（DB・IDE の起動）は進行役が済ませています。困ったら、いつでも進行役に声をかけてください。

| 版 | 内容 |
| --- | --- |
| 7C-3（2026-11-02） | 初版（開く・起動・選ぶ・由来・未確認・終わる） |
| 7C M2 確認（2026-11-03） | 現行の画面（`feature/explore` @ `6a6bd13` 以降）に合わせて見直し。「別の値を選ぶ」「コードを変えたとき」「確かめられなかったとき」「対応している環境」「残っている注意」を追加。3種類の表示（実測・推定・未確認）の早見表を追加 |

---

## 0. 画面の見方（最初に1分）

| 場所 | 何があるか |
| --- | --- |
| 左上「プレビュー」 | 題材のアプリの画面そのもの。ここで値を選びます |
| 中央（暗い点の背景） | **経路図**。選んだ値が、どのコードで描かれ、どこから来たかを図で描きます |
| 右端「詳細」 | 経路図の読み方を文章で出します。**迷ったら、まずここを読みます** |
| 右上「プロジェクトと実行」 | 題材のアプリを起動・停止する場所 |

画面の幅は **1600×1000 以上** をおすすめします（1440×900 でも使えますが、図の文字が小さくなります）。

### 3種類の表示（早見表）

この道具は、分かったことを3種類に分けて出します。**混ぜて出すことはありません。**

| 表示 | 意味 | 例 |
| --- | --- | --- |
| **実測** | 題材のアプリを実際に動かして、**起きたことを記録した** | このページを開いたときに、この SQL が実行された |
| **推定** | **コードの形から推測した**（実際の値の受け渡しを見たのではない） | この地名は `listings` 表の `region` 列から来たと考えられる |
| **未確認**／**特定していません** | 調べたが、**根拠をもって結べなかった**。推測で埋めずに、そう書いている | この文字が DB のどの列から来たかは分からない |

経路図では、**実線＝実測**、**破線＝推定**、**✕ の印＝ここから先は確かめられていない**です。

---

## 1. 開く

1. 右上「プロジェクトと実行」のパス欄に、進行役から伝えられたパス（例: `/home/…/poc/fixture-app`）が入っているか確かめます。
2. ［検出］を押します。`対応` と `poc01-fixture-app` が出れば成功です。

このとき中央と右端には「**プロジェクトを開きました（まだ起動していません）**」と出ます。**まだ何も図が無いのが正しい状態です。**

> 「合成デモを見る」というボタンがあります。これは**別のアプリの見本**（架空の物件一覧）で、画面の見方を試すためのものです。押すと「合成デモを表示中 — 別のアプリの見本です」と出ます。［デモを閉じる］で戻ります。今回の試用では押さなくてかまいません。

## 2. 起動する

1. 「プロジェクトと実行」の［起動する］を押します。
2. 数秒〜十数秒で、左上のプレビューに題材のアプリのページが出ます。上の帯に「実行中」と緑の点が出ます。

起動中、中央には「**開発サーバーを起動しています**」、起動が終わると「**まだ経路がありません**」と出ます。これも正しい状態です（まだ値を選んでいないため）。

## 3. ページを表示して、値を選ぶ

1. プレビューの上のアドレス欄に `/lin-a` と入れて［移動］を押します。「ケースA 直接対応」のページが出ます。
2. プレビューの［選択］を押します（選択モードに入ります）。
3. ページの中の地名（例: 「アオバ台」）を1つクリックします。
4. もう一度［選択］を押して、選択モードを抜けます。すると中央の経路図が大きく広がります。

> ページに戻りたいときは、プレビューの［ページを表示］を押します。パネルは ✕ で閉じるより［畳む］のほうが、ページがそのまま残ります。
> ページの中のリンクで別のページに移ったときは、↻（再読み込み）を押してから選んでください（リンクで移った直後の選択は、まだうまく結べません。右端に「切れた段階: 文書の同定」と出ます）。

## 4. 値の由来を見る

右端「詳細」のいちばん上を読みます。

* **この値の出所**: `poc.listings . region` — この地名は、DB の `listings` という表の `region` という列から来た、という意味です。
* その横の **「推定」**: この結び付きの一部は、実際に値の受け渡しを見たのではなく、**コードの形から推測した**ものだ、という印です。
* **★ いちばん弱いところ**: 推測が入っている箇所です。［ここを見る］を押すと、図のその線が選ばれます。

経路図では、**実線＝実際に起きたことを観測した関係**、**破線＝推定した関係**です。左下「表示設定」に凡例があります。

数字キー（1〜9）で図の番号の箇所を選べます。Esc で1段ずつ戻ります。［全体表示］（または 0 キー）で図全体を収めます。

> **どこまでが実測か。** 「このページを開いたときに SQL が実行された」「その SQL をこのコードの場所が実行した」は実測です。表と列は、実行された SQL の文そのものから読み取っています。「画面のこの地名が、その SQL の `region` 列の値だ」というつながりだけがコードの形からの推定です（右端に「N か所のうち 1 か所が推定です」と出ます）。1か所でも推定が入るので、経路全体は「推定」と表示されます。

## 5. 「未確認」の意味を理解する

1. アドレス欄に `/lin-g` と入れて［移動］します。「ケースG 否定例」のページが出ます。
2. ［選択］を押し、いちばん下の「**表示用の固定ラベル**」をクリックし、もう一度［選択］を押します。

右端「詳細」は、今度は次のように出ます。

| 行 | 表示 | 意味 |
| --- | --- | --- |
| 描画位置 | **特定済み**　実測　`src/app/lin-g/page.tsx:28` | この文字を画面に描いた**コードの場所**は、実際に確かめられた |
| 値の由来 | **未確認** | この文字が DB の**どの列から来たかは分かっていない** |
| 切れた段階 | 静的解析 | どの段で調べがつかなくなったか（ここではコードの解析） |
| 理由 | 参照の連鎖を解けません… | なぜ結べなかったか |

ここが大切です。

* 「**実測**」は描画位置（コードの場所）までの話です。値が DB から来たことが実測で分かった、という意味ではありません。
* 「**未確認**」は「調べたが、根拠をもって結べなかった」という意味です。**エラーや故障ではありません。推測で埋めることはしません。** このページの文字は、実際には DB の値ではなくコードに直接書かれた固定の文字です。だから結べないのが正しい答えです。

ほかに「描画位置: 特定できません」と出ることもあります。これは、選んだ要素を描いたコードの場所そのものが分からなかった、という意味です（例: 外部の部品の中の要素）。

## 6. 別の値を選ぶ

1. プレビューの［選択］を押します（畳まれたプレビューでも、［選択］1回で広がって選択モードに入ります）。
2. 同じページの別の値をクリックし、もう一度［選択］を押します。
3. 右端と経路図は、**新しく選んだ値の経路に置き換わります**（前の値の図は残りません）。

選び直しても結果が同じ形になるとは限りません。値ごとに「推定で DB まで結べた」「途中で切れた（未確認）」のどちらかが出ます。

> 候補が2つ以上あるとき（`/lin-c` など）は「2 候補のいずれか。1つに決めていません」と出ます。どちらかに決めつけないのが正しい表示です。

## 7. 終わる

「プロジェクトと実行」の［停止する］を押します。中央と右端は「**開発サーバーは停止しています**」になり、それまでの図は消えます（停止した後の古い情報は出しません）。もう一度［起動する］を押すと、新しい観測から描き直します。

## 確かめられなかったとき（未観測・未確認が出たとき）

「未確認」「特定していません」「特定できません」は、**この道具が根拠の無いことを言わないための表示**です。まず右端の「切れた段階」と「理由」を読み、次の表で対処してください。**対処しても同じなら、それがこの値についての答えです。** そのまま進行役に伝えてください（記録します）。

| 右端・プレビューに出る言葉（一部） | 何が起きたか | こうする |
| --- | --- | --- |
| 切れた段階: **文書の同定** ／「クライアント側の遷移」「再取得」 | ページ内のリンクで移った・ページが描き直された | ↻（再読み込み）を押してから選び直す |
| 「**保持対象外**」 | 古い通信の記録を整理済み（長く使ったとき） | ↻（再読み込み）を押してから選び直す |
| 切れた段階: **静的解析** | コードの解析で、値から DB への道筋が見つからない（固定の文字など） | 対処は要りません。これが答えです |
| 切れた段階: **実測との照合** ／「呼び出し位置を確かめられません」 | SQL は観測したが、どのコードが実行したかを確かめられない（コードの変更の直後など） | ↻ で読み直す。それでも同じなら、進行役に開発サーバーの再起動を頼む |
| 切れた段階: **実行SQLの SELECT 句** | 値が使う項目が、実行された SQL に無い | 対処は要りません。これが答えです |
| 描画位置: **特定できません** | 選んだ要素を描いたコードの場所が分からない（外部の部品など） | 別の要素（その中の文字など）を選んでみる |
| 「対応表がいまのソースの版と一致しません（再コンパイル待ち）」 | ページの組み立て直しが終わっていない | 数秒待ってから選び直す |

## コードを変えたとき（任意。進行役が案内した場合だけ）

試用の基本の流れでは、コードを変える必要はありません。進行役の案内でコードを変えて保存した場合は、次のように動きます。

* 選んでいた要素のファイル（またはそれを包むファイル）が変わると、約 1.5 秒で選択が解除され、「コードが変更されたため（ファイル名）、選択を解除しました。前の要素の情報は表示していません。…もう一度選択してください。」と出ます。**変更前の情報を変更後の要素に付け替えることはしません。** プレビューが描き直されてから、もう一度選んでください。
* 関係の無いファイルを変えたときは、選択はそのまま残ります。
* 変更の直後は、SQL の実行位置が「特定していません」になることがあります（実行されたコードの版を確かめられないため）。↻ で読み直す、または開発サーバーを再起動すると確かめられることがあります。

> **残っている注意（大切）。** コードを保存した**直後**に由来（DB の列）が出たときは、↻ でもう一度読み込んで、**同じ結果になることを確かめてください。** ファイルの書き込みの途中のごく短い時間に照合が重なった場合について、誤りが起きないことはまだ証明されていません（起きた例は見つかっていません）。違う結果が出たら、その画面を進行役に見せてください。

## 対応している環境（進行役が用意します）

| 項目 | 対応 |
| --- | --- |
| Node.js | 22 |
| Next.js | 16.4 系（確かめたのは 16.4.3）。開発サーバーは Turbopack（Next 16 の既定） |
| 題材 | `poc/fixture-app`（PostgreSQL を素の `pg` で直接読む Server Component のページ） |
| DB | 使い捨ての PostgreSQL 16（127.0.0.1:55432、架空のデータ） |
| ブラウザ | Chromium 系の実ブラウザ。画面は 1600×1000 以上 |

次は**まだ対応していません**（使うと「未確認」が増えるか、確かめていません）。

* ご自身のプロジェクト（要素の選択に設定の手書きが要る・テーブル名にスキーマが無い SQL の列が決まらないなど）
* Prisma など ORM 経由の SQL（SQL は見えますが、実行位置を確かめられません）
* ブラウザ側からの取得（`useEffect` で API を呼ぶ画面など）の値
* `件数: {n}` のように固定の文字と値が混ざった要素
* webpack・Next.js 15 以前・別の Node.js の版
* Codespaces などクラウドの転送を通した利用（実物では確かめていません）

## 困ったとき

| こうなった | こうする |
| --- | --- |
| 中央に何も図が無い | 値をまだ選んでいません。3. の手順で値を選びます |
| 図がパネルに隠れて見にくい | ［全体表示］（0 キー）を押します |
| 選んでも何も起きない | ［選択］が押された状態か確かめます。ページを移った直後なら ↻ を押してから選びます |
| 選んでいた値が勝手に消えた | コードが変更された可能性があります（上の「コードを変えたとき」）。もう一度選んでください |
| 「未確認」「特定していません」と出た | 故障ではありません。上の「確かめられなかったとき」の表を見てください |
| 見慣れない物件一覧や「千葉県」が出ている | 合成デモ（別のアプリの見本）です。［デモを閉じる］で戻ります |
| 「起動できていません」と出た | 進行役を呼んでください |
