## 3. この画面で新たに決めたこと

### 3.1 物理的実体と概念的モジュールの描き分け

> 指示5「物理的実体と概念的モジュールを区別してください」への回答。**形ではなく素材で分ける。**

| 種別 | 素材 | 影 | 該当 |
| --- | --- | --- | --- |
| **物理的実体** | 不透明・マットな金属／樹脂。面で光を受ける | **接地影を落とす** | ノートPC、開発サーバーのラック、PostgreSQL の筐体 |
| **概念的モジュール** | 半透明のガラス。縁だけが発光する。内部は透ける | **落とさない（浮いている）** | React コンポーネント、通信（HTTP交換）、実行SQL、テーブル、カラム |

**不透明＝そこに在るもの／半透明＝そう解釈したもの**、という一貫した規則にした。
概念モジュールは、対応する物理オブジェクトの**すぐ前に浮かべる**（React はノートPCの前、SQL はラックの前）ことで所属を示す。

### 3.2 実測と推定の区別（色に頼らない）

`03b` 5.1節・NFR-30 により、**一次符号は線種と形、色は補助**。立体でもこれを崩さない。

| 符号 | 立体での表現 |
| --- | --- |
| **実測** | **途切れない連続した光のビーム**。青 `#8aa4cc`。矢尻あり |
| **推定** | **等間隔に分節した光のビーム**（破線の立体版）。薄紫 `#9a8fc4`。矢尻あり。線上に「推定」の小札 |
| **★ 最弱環** | ⑦→③ のビームの上に ★ 付きの「推定」札。**ノードには付けない** |
| **切断** | 琥珀 `#c2a06e` の短いバー＋✕。線を消さずにそこで止める |
| **経路外** | 減光・脱彩度・発光なし。**削除しない**（UI-33） |

> グレースケールにしても、**連続／分節／✕／★** の4つの形だけで判別できる状態を保つ。

### 3.3 経路の折り返し（⑦→③）

`04b` 1.2節で決めた「外周を回らせず、下辺の専用レーンに通す」を立体でも守る。
**⑦ カラムから手前下へ降り、画面手前の低い弧を描いて左へ戻り、③ 通信へ入る。** ★と「推定」の札を弧の中央に置く。
参考画像の大きな紫の弧がすでにこの形になっており、方向だけ **⑦ → ③** と明示する。

### 3.4 ノードの上に置くもの

UI-15 / UI-20 のとおり、立体オブジェクトに添えるのは **バッジ・名称・識別子のみ**。
**所要時間（124ms / 98ms / 42ms）、行数（12行）、SQL全文、JSON は置かない。** すべて右の詳細パネルの担当である。

> 参考画像は SQL モジュールに `SELECT ... FROM properties WHERE ...` を描いているが、これは**形の説明として読める短い断片**にとどめ、実行されたSQL全文は詳細パネルに置く。

## 4.5 層をどこに置いたか

A案は「ブラウザ／サーバー／データベースの3層を左→右に並べる」構成だった（UI-30）。立体でもこの順序を保っている。

| 層 | 位置 | 置いたもの |
| --- | --- | --- |
| **ブラウザ** | 左・手前 | ノートPC（物理）＋ ① 表示された値 ／ ② コンポーネント ／ ③ 通信 |
| **サーバー** | 右上・奥 | 開発サーバーのラック（物理）＋ ④ サーバー処理 ／ ⑤ 実行SQL |
| **データベース** | 右下 | PostgreSQL の筐体（物理）＋ ⑥ テーブル ／ ⑦ カラム |

この配置により **⑦→③（最弱環の戻り）が手前の短い弧**になり、線の交差は **0本**になった。
`04b` 1.2節で平面版に入れた「戻りを外周に回さず専用のレーンに通す」という判断が、立体でもそのまま効いている。

## 6. 0.2〜0.3版での変更 — 地球と台座を外した

依頼者の指示により、**背景の地球**（「うしろの地球はなくていい。キャンバスでいい」）と、
**物理オブジェクトの下のガラス台座**（「サーバーとかブラウザの下にある四角い板はいらない」）を削除した。
地は `04b` の観測キャンバスと同じ扱い（淡い点のグリッド）に置き換えている。外したものは次のとおり。

| 外したもの | 理由 |
| --- | --- |
| 夜の地球・都市光・大気の輪郭・星 | 指示による |
| 「この配置は概念図です — 地理的な所在地ではありません」の注記 | 地球が無くなり、地理的に読まれる余地が消えたため（D-3 の解消） |
| カメラ操作の丸ボタン（回転／移動／視点を戻す） | **回す対象が無い。**席だけ置くと IX-23 / IX-24 に反する |
| 物理オブジェクトの下の**ガラス台座**（等角の板） | 指示による。**接地影は残したので、3.1節の「物理＝影を落とす／概念＝落とさない」の区別は保たれている** |

**残したもの**: 立体オブジェクト（接地影つきの物理的実体と、半透明の概念モジュール）、
発光するビーム、実在／設計案ならぬ**実測／推定の線種**、切断マーカー、経路外の減光、
右上の「全体表示」と拡縮。

> 画面の呼び名は「Physical View（立体表示）」のままにしてある。
> **地球は無くなったが、物体が奥行きのある空間に置かれているという性質は変わっていない**ためである。
> 呼び名を変えるかどうかは未決定（第5章 1 と同じく、`02c` の更新が必要になる）。
