## 0. 「画面」の数え方

本プロダクトは全画面遷移型ではなく、**モード × ペイン構成**で情報を配置する。したがって「画面」を次の2段階で数える。

| 単位 | 定義 | 例 |
| --- | --- | --- |
| **画面 (Screen)** | 独立した文脈を持ち、単独で到達・離脱できるもの | 探索モード、テーブル詳細、対応範囲 |
| **面 (Surface)** | 画面を構成する領域。同一の選択状態を異なる軸で射影する | プレビュー、フロー図、詳細パネル、タイムライン |

> **画面数を増やさないために**: 新しい情報が出てきたときの既定の置き場所は「既存画面の新しい面」ではなく「**既存の面の段階的開示の次の段階**」とする。面を増やすのは、射影の軸（現物 / 空間 / 時間 / 内容）が増えるときだけである。本設計で面は **4軸に固定** する（`02` 第5章）。

| 項目 | 内容 |

| **要件ID** | **FR-22**（中核）, FR-10, FR-11, FR-11b, FR-12, FR-18, FR-20, FR-20b, FR-20c, FR-21, FR-23, FR-24, FR-25, FR-40, FR-42, FR-43, FR-43b, FR-47, OBS-02, OBS-05, OBS-06, OBS-09, OBS-10, OBS-11 |
| **区分** | **A**（FR-20c / FR-24 / FR-25 / FR-43 / FR-47 は B） |

#### 面の構成

| 面 | 射影軸 | 最上位に表示 | 選択時に表示 | 区分 | 要件 |
| --- | --- | --- | --- | --- | --- |
| **F-1 ページナビ**（N2 左） | — | ページ一覧とルートパス | 選択ページのプレビュー読込 | A | FR-18 |
| **F-2 プレビュー**（N3 左） | **現物** | 開発サーバーの実際の描画 | 選択要素のハイライト。**特定できない場合は理由** | A | FR-10, FR-11, **FR-11b** |
| **F-3 フロー図**（N3 右） | **空間** | ノードのアイコン・名称・状態・線種のみ (UI-15, UI-20) | 選択経路の強調、他経路の減光 | A | FR-20, FR-20b, FR-21 |
| **F-4 詳細パネル**（N4 右） | **内容** | **経路サマリ**（主張・経路の確度・最弱環の名指し） | 番号付き縦リスト。各ステップの概要 → タブで詳細 | A | FR-23, **OBS-10, OBS-11** |
| **F-5 ドロワー**（N5 下） | **時間** | 既定は折りたたみ。ネットワーク（A）/ タイムライン（B）/ コンソール（B） | 選択ステップのバーを強調 | A/B | FR-40, FR-43, FR-43b, FR-47 |

#### 段階別の表示（UI-20〜22, 6.4節）

| 段階 | F-3 フロー図 | F-4 詳細パネル |
| --- | --- | --- |
| 0 未選択 | 種別アイコン・名称・状態・線種。**経路に推定が含まれる旨の1行** | **このページの概要**（下記 ※2） |
| 1 ホバー | 1行要約 + 観測性の語 + 最弱環には ★ | — |
| 2 クリック | 選択ノードを強調、経路を発光 | 経路サマリ + 番号付きリスト、選択ステップの概要タブ |
| 3 詳細を開く | — | タブ: 概要 / ヘッダ / パラメータ / **根拠** / 生データ |
| 4 参照へ | — | コードピーク（B）/ テーブル詳細（S-06）へ |

> **※1 F-3 の描画様式は Physical View（立体表示）である（`04d-physical-view-design.md`）。**
> これは**新しい画面でも新しい面でもない**。本書 0章の数え方によれば、画面は「独立した文脈を持ち、単独で
> 到達・離脱できるもの」、面は「射影の軸」であり、面は4軸に固定されている。Physical View は F-3 と同じ
> **空間**の射影を、立体として描いたものにすぎず、独立して到達・離脱できる文脈を持たない。したがって
> **S-04 の面の構成と画面総数（13画面）は変わらない。** `04d` 5章 #1 の「画面か表示方式か」は、本書の
> 数え方によって**表示方式に確定する**。
> なお **平面（A-2）と立体（Physical View）の表示切替を設けるかは未決**である。切替を設ける場合も、
> それは F-3 の描画様式の選択であって、画面・面・モードのいずれも増やさない。Phase 5A/5B の実装は
> 切替を置かず、立体のみを描いている（`04d` 5章 #1 / 6章の呼称の未決も継続）。

> **※2 段階0 の F-4 は「格納」ではなく「このページの概要」とする。**
> UI-13 と `03c` 5.1節は「選択が無いとき詳細パネルを格納」と定めていたが、Phase 4B の決定により
> **右の詳細パネルは固定・開閉しない**。格納できないため、空パネルを出す代わりに俯瞰サマリ
> （通信 N 件 ／ SQL N 件 ／ 計測できた時間 ／ 推定を含む旨 ／ 追跡できない箇所 ／ 表示中の経路）を置く。
> **ST-16（未選択を空パネルにしない）の目的は、格納よりもこの形のほうが直接に満たせる。**
> 件数は `LineagePath` と経路外のノードから算出する導出値であり、定数として持たない（`02d` 2.3節）。

> **F-2 プレビューを「現物」という独立した射影軸として扱う。** `01` 6.3節の3ビュー（空間 / 時間 / 内容）はプレビューを含んでいないが、UC-01 の起点はプレビューであり、**選択状態の同期対象として不可欠**である。`02` 第5章で4軸として定義し直す（要件への変更案として `02` 第9章に記載）。

### S-06. テーブル詳細

| 項目 | 内容 |
| --- | --- |
| **目的** | テーブルの定義・実データ・このテーブルに実際に発行されたSQLを1箇所で見る |
| **主に扱う情報** | `DbTable`, `DbColumn`, `RowSample`, `SqlStatement` |
| **最上位に表示** | カラム定義（名称・型・NULL可否・制約）。**実データの値は既定で非表示** |
| **選択時に表示** | カラム詳細（型・制約・PII候補・利用箇所への導線）。データプレビューは明示操作で N 行のみ |
| **他画面との関係** | ← S-04 の経路終端から（選択カラムが強調される）。→ S-07（逆方向トレース・B群） |
| **要件ID** | FR-50, **FR-51**, **FR-52**, **NFR-20**, NFR-26（B）, OBS-06 |
| **区分** | **A** |

> **A段階では実データの値を既定で非表示にする。** FR-51 は A群だが、PII推定マスク (NFR-26) は B群である。推定の無い段階で値を既定表示すると、個人情報が無防備に露出する。**既定を「定義のみ表示」とし、値は明示操作で N 行に限って開く**ことで、A段階でも露出しない（`02` 第7章）。

> **「このテーブルに発行された実測SQL」を A群で提供する。** これは実測 (L1) であり静的解析に依存しないため、逆方向トレース (FR-26, B群) の網羅性の問題を持ち込まずに「このテーブルは使われているか」に部分的に答えられる。ただし「観測された範囲で」という限定を必ず付す。

### S-07. 逆方向トレース結果（B群）

| 項目 | 内容 |
| --- | --- |
| **目的** | カラムから利用箇所（ページ・コンポーネント）を逆向きに辿る |

| **最上位に表示** | **「検出できた N 件」**（「全 N 件」と表現しない）、検出漏れが起きる条件の説明 |
| **選択時に表示** | 利用箇所のページ・コンポーネント・利用形態。選ぶと S-04 へ遷移し該当要素を強調 |
| **他画面との関係** | ← S-06。→ S-04 |
| **要件ID** | FR-26, **FR-27**, **OBS-07**, UC-02 |
| **区分** | **B** |

### S-09. プロセスと計装

| 項目 | 内容 |
| --- | --- |
| **目的** | アプリの実行状態を把握し、計装が有効かを知る |
| **主に扱う情報** | `ScriptDef`, `ProcessInstance`, `PortBinding`, `InstrumentationState`, `Container`（B） |
| **最上位に表示** | スクリプト一覧と起動・停止、プロセス状態（実行中 / 停止 / 異常終了 / 未起動）、PID、待ち受けポート、**起動元（IDE / 外部）** |
| **選択時に表示** | プロセス詳細、**計装パネル**（状態・理由・追加ファイル一覧（B）・収集範囲（B）） |
| **他画面との関係** | ← N0 の実行コントロールと計装インジケータ。← S-04 の `not-instrumented` 切断マーカー |
| **要件ID** | FR-30, FR-31, FR-35（B）, FR-37（B）, **INS-03, INS-08**, INS-05（B）, INS-07（B）, OBS-06 |
| **区分** | **A**（B群で充実） |

> **「起動元」の表示が INS-08 の情報的な実体である。** 外部起動のプロセスに接続している場合、計装は適用されず L1 情報は取得できない。この状態を「計装失敗」と表示すると、ユーザーは設定を疑って時間を失う。**「IDEから起動すれば取得できます」という解消手段つきで表示する。**
